
# Gallery Cafe Management System

## Project Overview
A web-based restaurant management system developed to manage restaurant operations.

## Main Features
- Customer Registration and Login
- Menu Management
- Table Reservations
- Food Pre-Ordering
- Order Management
- Staff Management
- Invoice Generation
- Admin Management

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
  

## Installation Requirements
- XAMPP
- PHP
- MySQL
- Web Browser

## Installation Steps
1. Install XAMPP.
2. Copy the project into the htdocs folder.
3. Create the gallery_cafe database.
4. Import the SQL database file.
5. Configure your local config.php using config.example.php.
6. Start Apache and MySQL.
7. Open the project in your browser.

## Security
Never publish actual database credentials or private customer information.
